# 서울우유 그릭요거트 최저가 알리미

쿠팡/네이버쇼핑에서 "서울우유 그릭요거트" 최저가를 하루 3번 확인하고,
설정한 목표가 이하로 떨어지면 스마트폰/PC로 푸시 알림을 보내는 앱입니다.
스마트폰 홈 화면에 아이콘으로 설치해서 쓸 수 있습니다 (PWA).

## 중요: 가격 수집 방식에 대한 안내

- **네이버쇼핑**: 네이버가 공식 제공하는 "검색 API"를 사용합니다 (무료, 안정적).
  여러 쇼핑몰(쿠팡 포함되는 경우도 많음)의 최저가를 비교해서 보여줍니다.
- **쿠팡**: 쿠팡은 일반 개발자용 상품 검색 오픈API를 제공하지 않습니다
  (쿠팡파트너스는 제휴 링크 생성용이라 목적이 다릅니다). 이 앱은 쿠팡 검색 페이지를
  best-effort로 시도하지만, **테스트 결과 쿠팡이 자동 요청을 403으로 차단**하는 것을
  확인했습니다. 즉, 쿠팡 가격은 안정적으로 잡히지 않을 수 있습니다.
  - 더 안정적으로 하려면 [쿠팡파트너스](https://partners.coupang.com) 가입 후 발급되는
    Open API 키(제휴용이지만 상품 검색/가격 조회 가능)를 사용하는 방법이 있는데,
    승인 절차가 필요해 이번 버전에는 포함하지 않았습니다. 필요하면 알려주세요, 연동을 추가해드릴 수 있습니다.
  - 무리하게 차단을 우회하는 방식(프록시, 헤더 위조 고도화 등)은 이용약관 위반 소지가 있어
    구현하지 않았습니다.

## 처음 설정하기

### 1. 의존성 설치 (이미 완료됨)
```bash
npm install
```

### 2. 네이버 API 키 발급 (필수 - 이게 없으면 가격 비교가 안 됩니다)
1. https://developers.naver.com/apps/#/register 접속 후 로그인
2. "애플리케이션 등록" → 이름 아무거나 입력
3. 사용 API에서 "검색" 체크
4. 등록 후 발급되는 **Client ID / Client Secret**을 `.env` 파일에 입력

```
NAVER_CLIENT_ID=발급받은값
NAVER_CLIENT_SECRET=발급받은값
```

### 3. 웹 푸시 키는 이미 생성되어 `.env`에 들어있습니다
(다시 만들고 싶으면 `npm run gen-vapid` 실행 후 출력값을 `.env`에 교체)

### 4. 서버 실행
```bash
npm start
```
브라우저에서 http://localhost:3000 접속

### 5. 스마트폰에 앱처럼 설치하기
같은 와이파이에서 PC의 IP로 접속 (예: `http://192.168.0.5:3000`) 후
- **iPhone(Safari)**: 공유 버튼 → "홈 화면에 추가"
- **Android(Chrome)**: 메뉴(⋮) → "홈 화면에 추가" / "앱 설치"

설치 후 "푸시 알림 켜기" 버튼을 누르면 그 기기로 알림이 옵니다.

> 주의: 웹 푸시는 HTTPS(또는 localhost)에서만 동작합니다. 외부에서 접속하려면
> ngrok, Cloudflare Tunnel 등으로 HTTPS 주소를 만들거나, 아래 "24시간 실행" 방법을 쓰세요.

## 24시간 계속 실행시키기

이 서버가 켜져 있어야 하루 3번 조회 + 목표가 감시가 동작합니다.

- **간단한 방법**: 안 쓰는 PC/미니PC에 이 폴더를 두고 `npm start`를 계속 켜둔다.
- **더 편한 방법**: Render.com, Railway.app 같은 무료/저가 클라우드에 배포하면
  PC를 안 켜놔도 됩니다. 배포가 필요하면 말씀해주세요, 이어서 세팅해드릴게요.

## 알림 시간 조정

`.env`의 아래 값으로 조정 가능합니다 (cron 표현식):
```
SUMMARY_CRON_TIMES=0 9,13,20 * * *   # 하루 3번: 9시, 13시, 20시
THRESHOLD_CHECK_CRON=*/30 * * * *     # 목표가 감시: 30분마다
```

## 폴더 구조

```
server/
  index.js          - Express 서버 + API
  db.js             - JSON 파일 기반 저장소 (data.json)
  priceFetchers.js  - 네이버쇼핑/쿠팡 가격 수집
  priceCheck.js     - 수집 + 알림 발송 로직
  scheduler.js       - 하루 3번 + 목표가 감시 스케줄
  push.js           - 웹 푸시 발송
public/
  index.html/app.js - 화면 (PWA)
  service-worker.js - 백그라운드 푸시 수신
  manifest.json     - 앱 설치 설정
```
